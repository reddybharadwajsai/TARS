# Workspace Rules

These rules govern the organization and management of the editorial workspace.

## Naming Conventions

- All filenames must use lowercase letters with underscores as separators.
- Chapter files should include the chapter number: chapter_1_title.md
- Meeting records should include the date: meeting_yyyy_mm_dd.md or similar date format.
- Generated documents should have descriptive names indicating their content and purpose.

## Folder Structure

The workspace uses the following standard folder structure:

- research_notes/ — Primary research materials and field notes
- meeting_records/ — Records of editorial meetings and planning sessions
- drafts/ — Working drafts and chapter manuscripts
- reference/ — Reference data, external source summaries, and background materials
- style_guides/ — Formatting and style documentation
- policies/ — Editorial policies and rules (this folder)
- output/ — All generated content and summaries

Do not create top-level folders without explicit permission from the lead editor.

## File Operations

- Moving files between folders should preserve the original filename unless a rename is necessary for consistency with the destination folder's naming convention.
- Deleting any document that contains more than 100 words of original content requires explicit editor approval.
- Backup copies of important documents should not be created within the workspace — this clutters the folder structure. Use the version control system instead.

## Access Boundaries

- All work must remain within this workspace directory.
- Do not reference, read, or attempt to access files outside the workspace boundary.
- External data should be copied into the reference/ folder rather than linked from outside locations.
